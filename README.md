# Tensra Ai

Create a modern, minimal, high-aesthetic mock redesign of Tensra (https://tensraai.com/), an AI services startup providing ERP and CRM integration services.

The redesign should eliminate generic AI template clutter, replace the circuit flow hero section, remove the demo section, and provide clean navigation to convey the services properly:
- Theme: Refined obsidian dark aesthetic (inspired by Linear, Vercel, and Scale AI) designed around the brand logo palette (#d9dadf silver, #1ac5ff electric cyan, #6b7591 slate, #0a0c10 deep dark background).
- Brand Logo:

- Navigation: Clean header with logo, navigation links (Services, Solutions, Architecture, Case Studies, Security & SLAs), and a "Book Consultation" CTA.
- Hero Section: High-impact typography, crisp value proposition ("Autonomous ERP & CRM data pipelines engineered for zero data loss"), dual action buttons ("Schedule Discovery Call" and "View Architecture"), and an interactive System Telemetry & Sync Stream card previewing live sync between NetSuite, SAP, and Salesforce (replacing the circuit animations).
- Verified Connectors Bar: Highlighting Salesforce, NetSuite ERP, SAP Business One, HubSpot, PostgreSQL, and QuickBooks.
- Core Services Matrix: 4 focused pillars with interactive tabs or cards (CRM & ERP Integration, Intelligent Document Intelligence, Autonomous Operational Agents, Custom Backend Infrastructure).
- Quantifiable Case Study: Highlighting Brikline Logistics with tangible metrics (-90% manual processing, 99.9% sync accuracy, 3-week deployment).
- 3-Step Engagement Model: Pipeline Audit & Schema Mapping -> Staged Rollout -> Production SLA & Observability.
- Interactive Discovery Consultation Modal: An intuitive 3-step project intake flow (select ERP/CRM stack, choose primary operational bottleneck, pick consultation time or request quote).
